# Совместимость VPN Manager с роутерами Keenetic

Анализ модельного ряда Keenetic и совместимости с проектом VPN Manager.

## Обзор требований проекта

### Минимальные требования

| Требование | Значение | Примечание |
|------------|----------|------------|
| **Архитектура CPU** | aarch64, mipsel, mips | Все три архитектуры поддерживаются (sing-box 1.12.17-extended) |
| **RAM** | ≥256 MB | Рекомендуется ≥512 MB для стабильной работы |
| **Flash/USB** | ext4 USB | Для Entware и VPN Manager |
| **KeeneticOS** | 3.x+ | Требуется поддержка OPKG |
| **Модуль TPROXY** | xt_TPROXY.ko | Для прозрачного проксирования UDP |
| **Модуль xt_socket** | xt_socket.ko | Для TPROXY |

### Критические компоненты KeeneticOS

Для работы VPN Manager необходимо установить следующие компоненты в настройках роутера:

1. **Пакет OPKG** — базовое требование для Entware
2. **Модули ядра Netfilter** — для TPROXY (в некоторых моделях не предустановлено)

**Что нужно для поддержки MIPSEL:**
1. Скачать/собрать `sing-box` для `linux-mipsle-softfloat`
2. Скачать архив Entware `mipsel-installer.tar.gz`
3. Адаптировать `install-singbox.sh` для автоопределения архитектуры
4. Протестировать на реальном устройстве

**Ограничения MIPSEL:**
- Меньше производительности CPU (особенно для шифрования)
- Меньше RAM (256 MB на грани)
- Возможны проблемы с TPROXY (не на всех моделях есть модуль)

## Известные ограничения

### TPROXY на разных моделях

| Модель | Модуль TPROXY | Примечание |
|--------|---------------|------------|
| KN-1812 (Ultra) | ✅ Работает | **Протестировано**, требуется компонент "Модули ядра Netfilter" |
| KN-1811 (Ultra) | ✅ Работает | **Протестировано** |
| KN-2710 (Peak) | 🔶 Ожидается | Не тестировалось, предположительно аналогично |
| KN-1012 (Giga) | 🔶 Ожидается | Не тестировалось |
| KN-3811/3812 (Hopper) | 🔶 Ожидается | Не тестировалось, другой процессор (MT7986B) |
| Старые MIPSEL | ⚠️ Неизвестно | Нужно проверять на конкретной модели |

### Проверка TPROXY на роутере

```bash
# Проверить наличие модуля
find /lib/modules -name "xt_TPROXY.ko" 2>/dev/null

# Или через lsmod после загрузки
lsmod | grep -i tproxy
```

Если модуль отсутствует, VPN Manager будет работать в ограниченном режиме:
- ✅ TCP-трафик через VPN (redirect)
- ❌ UDP-трафик (требуется TPROXY)

## FAQ

### Можно ли использовать USB-хаб?

**Да!** Keenetic поддерживает USB-хабы. Можно одновременно подключить:
- USB-флешку с Entware и VPN Manager
- USB-модем (4G/LTE)
- Другие USB-устройства (принтер и т.д.)

**Рекомендации:**
- Используйте **активный USB-хаб** (с внешним питанием), особенно если подключаете USB-модем
- Пассивный хаб может не обеспечить достаточно питания для модема

### Почему мой KN-1810 не поддерживается сразу?

KN-1810 использует архитектуру MIPSEL, а текущий проект собран только для aarch64. Для поддержки MIPSEL нужно:
1. Добавить бинарник sing-box для MIPSEL
2. Протестировать на реальном устройстве (256 MB RAM — на пределе)

### Можно ли использовать проект на KN-1012 (Giga без Wi-Fi)?

Да! KN-1012 — aarch64 с 512 MB RAM. Отлично подходит как VPN-шлюз без Wi-Fi функций.

### Будет ли работать на Zyxel Keenetic (старые модели)?

Старые модели Zyxel Keenetic (до 2017) обычно используют MIPSEL и имеют мало RAM (64-128 MB). Скорее всего, они не будут поддерживаться из-за ограничений ресурсов.
