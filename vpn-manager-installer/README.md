# VPN Manager — установщик

Эта папка кладётся на флешку вместе с `install/` и `etc/` и ставится автоматически. Описание проекта, требования и порядок установки — в [README.md уровнем выше](../README.md).

## Состав

- `install-singbox.sh` — установка и переустановка; `uninstall-singbox.sh` — удаление
- `sing-box-*.tar.gz` — сборки sing-box Extended **1.14.1-extended-2.7.2** для aarch64, mips и mipsel. Только эта версия: конфиг пишется в формате sing-box 1.14, установщик сам обновляет старые роутеры и переводит их конфиг
- `scripts/` — службы и фоновые задачи: правила маршрутизации (`S98singbox-rules`), sing-box (`S99sing-box`), DNS-over-TLS, обновление списков и подписок, автопереключение сервера
- `web/` — веб-панель: `index.html`, `js/app.js`, API на shell-CGI в `web/api/`
- `config/` — стартовые списки доменов и подсетей, шаблоны настроек
- `docs/` — автоустановка с флешки, совместимость моделей Keenetic, заметки об AmneziaWG

## Установка вручную

```sh
cd /opt/vpn-manager-installer
sh install-singbox.sh
```

Панель после установки: `http://<адрес роутера>:8001`.
