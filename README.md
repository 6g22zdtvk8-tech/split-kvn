# Split-KVN — VPN Manager для Keenetic

Раздельный VPN на роутере Keenetic: сайты и сервисы из списков идут через VPN, всё остальное — напрямую. Движок — [sing-box](https://github.com/shtorm-7/sing-box-extended), управление — веб-панель на самом роутере.

## Возможности

- **Раздельная маршрутизация** по доменам и IP-подсетям, отдельно для TCP+UDP и только UDP. Готовые списки обновляются автоматически, свои можно добавлять в панели
- **Политики по сегментам сети**: для каждого сегмента Keenetic — «через списки», «всё через VPN» или «напрямую»
- **Протоколы**: VLESS (Reality, WS+TLS, XHTTP), VMess, Trojan, Shadowsocks, WireGuard
- **Подписки**: Base64, SIP008, V2Ray JSON, Clash YAML; автообновление, в том числе для подписок с привязкой к устройству (HWID)
- **Несколько соединений сразу**: отметьте до 20 серверов из разных подписок, выберите главный — остальные держатся в горячем резерве. Если главный не отвечает, соединения уходят на резервный за секунды, без перезапуска
- **Автопереключение сервера** при недоступности текущего (в режиме одного соединения)
- **Kill switch**: пока VPN перезапускается, трафик для VPN блокируется, а не уходит напрямую
- **Защита DNS**: домены из списков резолвятся через DNS-over-TLS, подменённые ответы провайдера не действуют
- **Свой VPN-сервер** (VLESS + WebSocket) для подключения телефонов и ноутбуков вне дома, с QR-кодами
- **Резервная копия**: одна кнопка — скачать все настройки, одна — восстановить
- **Без телеметрии**: панель ничего никуда не отправляет

## Что нужно

- Роутер Keenetic с USB-портом и KeeneticOS 4.x–5.x. Установка с флешки «с нуля» рассчитана на aarch64: в `install/` лежит офлайн-установщик Entware для этой архитектуры. Для mips/mipsel есть сборки sing-box, но Entware нужно поставить заранее (см. ниже)
- USB-флешка от 1 ГБ, отформатированная в **ext4** (на Windows — например, DiskGenius; на Linux — `mkfs.ext4`)
- Компонент «OPKG» в настройках Keenetic
- sing-box Extended **1.14.1-extended-2.7.2** — лежит в установщике и ставится им сам. Более старые сборки (1.12.x) не подходят: панель пишет конфиг в формате sing-box 1.14

## Установка с флешки

1. Отформатируйте флешку в ext4.
2. Скопируйте на неё содержимое этой папки целиком: в корне флешки должны оказаться `install/`, `etc/` и `vpn-manager-installer/`. На Windows это же делает `prepare-usb.ps1` (он заодно переводит скрипты в формат строк Linux).
3. Вставьте флешку в роутер.
4. В веб-интерфейсе Keenetic откройте «OPKG», выберите флешку носителем и сохраните.
5. Подождите 5–10 минут: сначала офлайн ставится Entware, затем автоматически — VPN Manager.
6. Откройте панель: `http://<адрес роутера>:8001`.

Подробности и диагностика — в [docs/auto-install-guide.md](vpn-manager-installer/docs/auto-install-guide.md).

### Установка на роутер, где Entware уже есть

```sh
cd /opt/vpn-manager-installer
sh install-singbox.sh
```

### Обновление со старой версии (sing-box 1.12)

Тот же запуск `sh install-singbox.sh` из свежей папки установщика. Он сам:

- заменяет sing-box на 1.14.1-extended-2.7.2 из своей папки;
- переводит существующий конфиг в формат 1.14 (DNS-серверы, правила определения сайтов, WireGuard, XHTTP) — серверы, подписки и списки остаются;
- переносит активные сессии панели на флешку: после обновления и перезагрузок вход не слетает.

Пароль панели при полной переустановке сбрасывается — задайте его заново в «Настройки → Авторизация». Откат: вернуть прежний файл `/opt/bin/sing-box`. Старый 1.12 читает новый конфиг одного подключения, но не режима «несколько подключений» — перед откатом переключитесь в «Одно подключение».

## Первые шаги в панели

1. **Настройки → Авторизация**: сразу включите пароль. По умолчанию вход без пароля, панель доступна только из домашней сети.
2. **VPN**: добавьте подписку или конфигурацию (ссылка `vless://`, `ss://`, `trojan://`, `vmess://` или файл WireGuard `.conf`) и активируйте сервер.
3. **Домены / Подсети**: проверьте списки; при необходимости добавьте свои.
4. **Настройки → Резервная копия**: скачайте бэкап и храните его как пароль — в нём ссылки подписок и ключи серверов.

## Где что лежит на роутере

- Панель — `/opt/share/www/vpn-manager/`
- Настройки, конфигурации, подписки, списки — `/opt/etc/vpn-manager/`
- Конфиг sing-box — `/opt/etc/sing-box/config.json`
- Службы — `/opt/etc/init.d/S98singbox-rules` (правила), `S99sing-box` (sing-box)
- Журнал — `/opt/var/log/messages`

## Удаление

```sh
sh /opt/vpn-manager-installer/uninstall-singbox.sh
```
